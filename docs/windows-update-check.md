# Windows 자동 업데이트 실기기 확인 절차

학교 PC에서 이전 버전 → 새 버전 [지금 업데이트]가 되는지, SmartScreen·백신이 어떻게 반응하는지 확인하는 순서입니다. 아래는 v1.7.4 → v1.7.5 기준이며, 다음 릴리즈 때는 버전 번호만 바꿔 씁니다.

**원칙: 실제 학교 자료 원본은 건드리지 않습니다.** 원본 폴더를 복사한 시험용 폴더에서만 합니다.

## 1. 준비 (5분)

1. 바탕화면 등에 새 폴더 `꼬미입시_업데이트시험`을 만듭니다.
2. 쓰고 있는 꼬미입시 폴더의 `data` 폴더를 통째로 이 시험용 폴더에 **복사**합니다(잘라내기 아님).
3. GitHub 릴리즈 v1.7.4 페이지에서 `kkomi-ipsi.exe`를 받아 시험용 폴더에 넣습니다.
   - 주소: `https://github.com/purnpado/kkomi_ipsi/releases/tag/v1.7.4`
4. (선택) 받은 파일이 올바른지 PowerShell로 지문값을 확인합니다. 같은 릴리즈의 `SHA256SUMS.txt`에 적힌 값과 같아야 합니다.
   ```powershell
   Get-FileHash .\kkomi-ipsi.exe -Algorithm SHA256
   ```

## 2. 첫 실행 반응 기록

1. `kkomi-ipsi.exe`를 두 번 눌러 실행합니다.
2. 다음 내용을 적습니다.
   - [ ] SmartScreen "Windows의 PC 보호" 창이 떴는가? 떴다면 [추가 정보] → [실행]으로 열렸는가?
   - [ ] 백신(V3, 알약 등)이 막거나 검사 창을 띄웠는가? 떴다면 백신 이름과 문구를 사진으로 남깁니다.
   - [ ] 실행 뒤 파일 이름이 `꼬미입시.exe`로 바뀌었는가? (v1.6.7부터 처음 실행할 때 스스로 바꿉니다)
3. 학년부장 계정(또는 평소 계정)으로 로그인합니다. 버전이 v1.7.4로 보이는지 확인합니다.

## 3. 자동 업데이트

1. 로그인하면 업데이트 안내 창이 뜨거나 화면에 "🚀 새 버전 v1.7.5 출시!"가 보여야 합니다.
2. [지금 업데이트]를 누릅니다. "새 버전을 내려받고 지문값을 확인하는 중입니다…"가 보이는 동안 창을 닫지 않습니다.
3. 프로그램이 저절로 꺼졌다가 새 버전으로 다시 켜져야 합니다.
4. 다음 내용을 적습니다.
   - [ ] 다시 켜진 프로그램이 v1.7.5인가?
   - [ ] 이때 SmartScreen·백신이 다시 막았는가? (새 실행 파일이라 다시 뜰 수 있습니다)
   - [ ] 시험용 폴더에 `업데이트전_백업\<날짜-시각>_v1.7.4` 폴더가 생겼는가?
   - [ ] 시험용 폴더의 실행 파일 이름이 `꼬미입시.exe`인가?
   - [ ] 프로그램을 한 번 끄고 다시 켠 뒤 `꼬미입시.exe.old` 파일이 지워졌는가?

## 4. 업데이트 뒤 자료 확인

- [ ] 같은 비밀번호로 로그인된다.
- [ ] 학생 명렬표·성적이 그대로 보인다.
- [ ] 원서·결과 → 원서 관리, 원서대장에서 기존 원서가 그대로 있다.
- [ ] 입시 분석이 열리고 숫자가 업데이트 전과 같다.
- [ ] 새 기능: 관내 공유 결과 → **자료 검증** 화면이 열린다.
- [ ] 새 기능: 상담 화면 위쪽 "지원 원서 · 나이스 원서 입력값" 칸이 보인다(특성화고 원서가 있는 학생).
- [ ] 인쇄 미리보기(원서대장 등)가 열린다.

## 5. 문제가 생겼을 때

| 증상 | 할 일 |
|---|---|
| "릴리즈 조회 실패", "내려받지 못했습니다" | 학교망이 GitHub를 막았을 수 있습니다. 문구를 사진으로 남깁니다(프로그램이 Gitea도 시도합니다). |
| "프로그램 폴더에 파일을 쓸 수 없습니다" | 폴더 권한 문제입니다. `Program Files` 같은 곳이 아닌 바탕화면·문서 폴더에서 다시 해 봅니다. |
| "새 버전으로 바꿨지만 자동으로 실행하지 못했습니다" | 시험용 폴더의 `꼬미입시.exe`를 직접 실행합니다. 백신이 막았을 가능성이 큽니다. |
| 업데이트 뒤 로그인이 안 되거나 자료가 비어 보임 | 프로그램을 끄고, `업데이트전_백업\...` 폴더 안 내용을 `data`에 덮어쓴 뒤 v1.7.4로 다시 열어 봅니다. 원본 폴더는 처음부터 건드리지 않았으므로 안전합니다. |

## 6. 끝나면

- 2~4장의 체크 결과와 사진을 정리해 알려 주시면 `docs/current-work.md`에 기록합니다.
- 시험용 폴더는 지웁니다. 학생 자료 사본이 들어 있으므로 휴지통도 비웁니다.
