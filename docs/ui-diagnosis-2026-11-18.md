# 꼬미입시 UI/UX 진단 (v1.7.3, 2026-11-18)

> 코드 수정 없이 진단만 했다. 기준: Web Interface Guidelines(vercel-labs, `web-design-guidelines` 스킬)에서 데스크톱 앱에 해당하는 항목, WCAG 2.2 대비 기준(일반 글자 4.5:1, 큰 글자 3:1).
> 방법: ① 화면 코드 정적 점검(`frontend/src` 120여 파일) ② 서버 모드 + Chrome 자동 측정(가상 자료, 1366×768, 라이트·다크 — 글자/바탕 대비는 실제로 칠한 색을 읽어 반투명 바탕을 겹쳐 계산, 그라데이션 버튼은 제외) ③ 자동 캡처 42장.
> 분류: **A 지금 고칠 것**(쓰는 데 걸림, React 전환과 무관하게 이어짐) / **B 기준만 정해 둘 것**(값을 정해 CSS 변수·문서로 두고 React 때 그대로 사용) / **C React 전환 때 할 것**(지금 고치면 다시 해야 함).

## 3. 권하는 진행

1. **A 묶음(반나절~1일)**: #1 라이트 보조 글자 색, #2 배지·보조문구 12px 이상, #3 클릭되는 칸 키보드, #4 닫기 버튼 이름, #5 포커스 표시, #7 알림 전달, #8 다크 대비, #13 용어·말줄임. → 측정 스크립트로 전후 비교.
2. **B 기준(반나절)**: 색 이름표(바탕·글자 3단계·테두리·판정 5색, 라이트/다크), 글자 크기 단계(12·13·14·16·20·24), 숫자 표 규칙(tabular-nums), 아이콘 한 종류, 용어표 → `docs/` 문서와 CSS 변수.
