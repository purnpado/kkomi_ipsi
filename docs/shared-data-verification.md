# 관내 공유 자료 검증 (2026-11-18)

관내 공유 결과 → **자료 검증**. 다른 학교가 보낸 익명 원서 결과(학교·학과·전형, 합격/불합격, 점수, 산출 기록)를 점검해, 잘못 입력된 자료가 관내 합격선·추세·학과 지망 전략·**상담 판정 근거**에 섞이지 않게 한다.

## 왜 필요한가

- 공유 파일에는 다른 학교가 직접 입력한 커트라인·경쟁률은 들어가지 않는다(각 학교 PC에만 있음). 들어가는 것은 학생 한 명 한 명의 원서 결과다.
- 다른 학교가 불합격을 합격으로 잘못 체크하거나 점수를 잘못 고치면, 관내 합격 최저점이 내려가고 판정이 "안정" 쪽으로 쏠린다.

## 기준 학년도

- **2027 고입부터** 점검을 거친 관내 자료만 쌓는다(`SharedBaselineYear`).
- 그 이전 다른 학교 자료와 옛 형식(V1) 파일은 처음 받을 때 "통계 제외"(학년부장이 다시 넣을 수 있음). **우리 학교 자료는 항상 포함.**
- 받은 자료와 넣고 뺀 표시는 인수인계 파일로 다음 학년도 폴더에 이어진다.

## 점검 규칙 (`internal/database/shared_verify*.go`)

| 수준 | 코드 | 내용 |
|---|---|---|
| 오류 | `range` | 점수가 0 미만이거나 그 전형 만점 초과 |
| 오류 | `unknown` | 산출식에 없는 학교·전형 이름 |
| 오류 | `status` | 알 수 없는 결과 값 |
| 확인 필요 | `too_low` | 만점의 15%도 안 되는 점수(소수점 위치 오타 등) |
| 확인 필요 | `noscore` | 결과는 있는데 점수 0 |
| 확인 필요 | `snapshot` | 원서 점수가 산출 기록과 다름(손으로 고친 점수) |
| 확인 필요 | `low_accepted` | 합격 점수가 다른 학교 합격 자료보다 크게 낮고, **그보다 점수가 높은 다른 학교 1차 불합격(일반고 미배정)이 같은 학과에 있음**(학과를 적지 않은 불합격은 학교 전체에서 근거로 봄) |
| 확인 필요 | `high_rejected` | 1차 불합격(일반고 미배정)인데 점수가 다른 학교 합격자 대부분보다 높음 |
| 참고 | `formula` | 그해가 아닌 다른 요강 학년도 산출식으로 계산(학교 단위로 묶어 보임) |
| 묶음 | 정원 초과 | 관내 합격자가 공식 경쟁률 화면의 모집정원보다 많음 |

- 비교 자료: 같은 학년도·학교·전형(비교 자료 5건 이상이면 학과 단위)의 **다른 학교** 합격 점수와 우리 학교 합격 점수. 자기 학교 점수는 비교에서 뺀다.
- 기준선 = 1사분위 − K × 사분위 범위(최소폭 만점의 5%), K = 0.75.
- 미달(불합격자 없음)이면 낮은 점수로 합격해도 정상이므로 걸지 않는다. 학과 단위로도 같다: 인기 학과 불합격자가 미달 학과·2지망 배정 학과의 낮은 합격자보다 점수가 높은 것은 정상이므로, 같은 학과 불합격만 근거로 쓴다(`SharedRejectSameDept`).
- 원서 한 건 점검에서 점수가 범위 밖(만점 초과·만점의 15% 미만)이거나 학교명을 모르는 원서는 비교 기준과 근거에서 뺀다(`SharedSkipBadRefs`). 만점 초과로 잘못 적힌 불합격이 다른 학교의 정상 합격자를 "더 높은 불합격이 있다"로 걸던 것을 막는다.

## 검출률 측정 (`go run ./tools/verifysim`)

가상 학교들의 결과를 만들고 오류 8종을 3% 확률로 섞어 30회 반복한다(실제 산출 규칙의 학교·전형·만점 사용). 결과 `test-data/검증시뮬레이션/보고서.md`.

### 가상 자료 생성기 두 가지

| | 단순형(`-gen basic`, 처음 기준값을 정할 때) | 현실형(`-gen real`, 기본, 2026-11-18 재점검) |
|---|---|---|
| 학과 | 없음(학과 비교 경로를 한 번도 거치지 않음) | `server-data/highschools.json` 2027 학과별 모집정원 |
| 선발 | 전형마다 합격선 하나, 모든 전형에 불합격자 있음 | 관내 지원자 전체를 점수 순 1지망 → 남은 자리 2지망으로 선발, 지원 배율이 전형마다 달라 **미달**이 생김 |
| 참여 학교 | 모든 지원자가 참여 학교 학생 | 관내 중학교 50곳 중 8곳(또는 4곳)만 공유 → 비교 자료가 성김(특별전형 정원 12명 등) |
| 학교별 편차 | 없음 | 중학교마다 점수 평균이 다름(표준편차 만점의 4%) |
| 2단계 탈락 | 15% | 마이스터고 15%, 특성화고 3% |
| 일반고 | 학교당 20~40명, 불합격 약 40% | 학교당 60~140명, 미배정 약 7% |
| 정원 외 | 없음 | 특수교육대상자 등 정원 외 합격을 통계 제외 표시 없이 보낸 원서(`extra_unmarked`, 전형·학교당 2%) |
| 견딤 시험 | — | `-rejdept2 0.3`: 불합격자 학과를 1지망 대신 2지망으로 적는 학교가 섞임(입력 관행 차이) |

단순형은 모든 전형에 불합격자가 고르게 있고 학과가 없어, 현실에서 오탐이 가장 많이 나는 경우(미달 학과·2지망 배정 학과의 낮은 합격자)를 재지 못했다.

소수점 오타·만점 초과·학교명 오타·결과 값·이전 산출식은 전후 모두 100%. 손으로 고친 점수도 100%이고, 현실형 4곳에서 1건은 이미 만점이라 고쳐도 점수가 그대로인 가상 자료 쪽 사정이다.

- **판단**: 현실형 8곳 기준 변경 전에는 "확인 필요" 351건(정상 243 + 실제 오류 108) 중 약 70%가 정상 자료였다. 변경 후에는 걸린 것이 거의 모두 실제 오류다. 크게 낮은 뒤바뀜 검출은 1건(0.8%p) 줄었다. 견딤 시험(불합격자 학과를 2지망으로 적는 학교 30%)에서는 4.6%p 줄었지만 오탐이 0.9%에서 0.2%로 줄었다. 그래서 두 변경을 반영했다.
- **정원 외 미표시**(50.6% → 28.2%): 변경 전에 걸리던 것은 다른 학과 불합격자 덕에 "우연히" 걸린 것이다. 실제로 합격한 학생이라 낮은 합격의 앞뒤를 따지는 규칙으로는 원래 잡기 어렵다(아래 한계).
- **K를 더 낮추지 않은 이유**: 현실형에서는 K=0.5·0.25로 내려도 오탐이 거의 없었다(크게 낮은 뒤바뀜 8곳 87.0% → 89.4% → 90.2%). 하지만 단순형에서는 오탐이 0.0% → 0.3% → 1.2%로 늘었다. 가상 자료 하나에 맞추지 않으려고 K=0.75를 유지했다. 학과 최소 건수 3·8, IQR 최소폭 2·3%도 차이가 1~3%p 안이어서 그대로 두었다.
- 회귀 테스트: `TestSharedVerifySimulationRecall`(단순형)과 `TestSharedVerifyRealisticSimulation`(현실형: 2지망 배정 합격 오탐 0, 크게 낮은 뒤바뀜 75% 이상, 정상 확인 필요 0.5% 이하).
- 다시 재기: `go run ./tools/verifysim -seeds 30 -schools 8 -k 0.75`(`-schools 4`, `-gen basic`, `-rejdept2 0.3`, 비교용 `-samedept=false -skipbad=false`).

## 통계 관점 재점검 (2026-11-18, Data 플러그인 `statistical-analysis`·`validate-data` 기준)

| 방식 | 약점 | 대안·조치 |
|---|---|---|
| 사분위 범위(IQR) 기준선 | 비교 자료가 3~5건이면 사분위수 자체가 크게 흔들린다(표본 5건의 Q1은 사실상 두 번째 값). 분포가 두 봉우리(인기·비인기 학과 섞임)면 IQR이 넓어져 둔해진다. | IQR 최소폭(만점 5%)이 작은 표본의 지나친 민감함을 막는다. 실제 판정력은 아래의 순위 근거에서 나온다. 표본 크기별로 K를 바꾸는 방식은 현실형에서 이득이 1~3%p뿐이라 넣지 않았다. |
| "더 높은 1차 불합격이 있을 때만" | 사실상 **순위 역전 검사**다(점수 순 선발인데 낮은 사람이 붙고 높은 사람이 떨어짐). 분포 가정이 없어 튼튼하지만, 학과 지망 배정이 있으면 학교 전체 단위의 역전은 정상이다. | **같은 학과 단위로 바꿈(반영)**. 불합격자 학과를 2지망으로 적는 학교가 섞이면 검출이 조금 준다(견딤 시험). |
| 자기 학교 제외 | 한 학교가 통째로 틀려도 스스로를 기준 삼지 않는 장점이 있다. 대신 참여 학교가 적으면 비교 자료가 더 모자란다(4곳에서 검출률이 낮은 주원인). | 유지. 학교가 늘수록 나아진다. |
| 학과 → 학교 전체 전환 | 학과 자료가 모자라 학교 전체로 넘어가면 다른 학과 점수와 비교하게 된다(Simpson 역설 꼴: 학교 전체로는 낮아도 그 학과 안에서는 정상). | 기준선은 전환하되, 근거(더 높은 불합격)는 같은 학과에서 찾게 해 전환에 따른 오탐을 막았다. |
| 오류 원서가 비교 기준에 섞임 | 만점 초과로 잘못 적힌 불합격이 다른 정상 합격을 거는 연쇄 오탐. | **범위 밖 원서를 비교 기준·근거에서 뺌(반영)**. |
| 학교 단위 치우침(파일 전체가 다른 산출식·일괄 가산) | 원서 하나하나는 그럴듯해서 지금 규칙으로는 못 잡는다. | 학교별 순위 편향 검정 후보: 같은 학과 안 백분위의 학교 평균을 보거나 Mann-Whitney 검정을 하고, 학교 수만큼 여러 번 검정하므로 Bonferroni 보정을 한다. 다만 실제 중학교별 성적 편차(현실형 표준편차 4%)와 구분하기 어렵다. 가상 오류 종류부터 만들어 재 본 뒤 넣는다(미구현). |
| 다중 비교 | 원서 수만 건을 각각 판정하므로 오탐률 0.1%도 수십 건이 된다. | 지금 변경으로 현실형 오탐 0건이다. 실제 자료에서 걸린 건수를 학교·전형별로 보고 다시 확인한다. |

## 한계

- 합격선 근처에서 합격·불합격이 뒤바뀐 경우처럼 그럴듯하게 틀린 값은 일부만 잡는다(약 30~50%).
- 관내 학교가 적으면(4곳) 비교 자료가 모자라 검출률이 낮다(크게 낮은 뒤바뀜 64~71%). 자료가 쌓일수록 정확해진다.
- **정원 외 합격을 통계 제외로 표시하지 않은 원서**는 실제 합격이라 앞뒤가 맞지 않는 곳이 없다. 같은 학과에 더 높은 불합격이 있을 때만 걸린다(현실형 8곳 28%). 미달 학과에서는 정상 하위 합격과 구별할 수 없다. 담임·학년부장이 통계 제외를 표시하도록 안내하는 것이 우선이다.
- 같은 학과 근거 규칙은 불합격자의 학과가 **1지망 학과**로 적힌다고 가정한다. 2지망으로 적는 학교가 많으면 검출이 조금 줄어든다(오탐은 늘지 않음).
- 가상 자료는 두 종류 모두 직접 만든 것이다. 지원 배율(일반 1.1배·마이스터 1.6배 중심), 학과 인기, 학교별 편차, 2단계 탈락률은 추정값이다. 학교에서 실제 공유 자료를 받으면 걸린 건수와 내용을 보고 기준값을 다시 확인한다.
- 오류를 섞지 않은 기존 시뮬레이터 자료(`tools/simulate`)로는 이번 변경 뒤에 다시 재지 않았다.

## 운영

1. 관내 공유 파일을 가져온다 → 자료 검증이 바로 점검한다.
2. 오류·확인 필요가 있는 학교의 [자세히]를 열어 분포 그림과 내용을 본다.
3. 의심되는 원서만 [통계에서 빼기], 파일 전체가 의심되면 학교 줄의 [통계에서 빼기]. 언제든 다시 넣을 수 있다.
4. [확인 요청 문구 복사]로 그 학교에 고쳐 달라고 알린다. 고친 파일을 다시 받으면 새 자료로 바뀌고 다시 점검된다.
5. 학년부장만 넣고 뺄 수 있고, 담임·진로부장은 점검 결과만 본다.
