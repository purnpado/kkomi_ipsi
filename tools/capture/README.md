# 화면 자동 캡처 (개발용)

서버 모드로 띄운 꼬미입시를 이 컴퓨터의 Google Chrome(화면 없이)으로 열어 역할별 주요 화면을 라이트·다크로 찍습니다.
가상 시뮬레이션 자료(`test-data/시뮬레이션/열람용/<학교>/data`) 사본만 쓰며 실제 학교 `data`에는 손대지 않습니다. 배포 빌드에는 들어가지 않습니다.

```bash
zsh tools/capture/run.sh                    # 가람중학교 자료로 전체(학년부장·담임·진로부장)
zsh tools/capture/run.sh 나래중학교 homeroom  # 다른 학교, 담임 화면만
```

- 준비: `go run ./tools/simulate`로 열람용 자료를 먼저 만듭니다. 처음 실행하면 `puppeteer-core`를 설치합니다(Chrome은 내려받지 않고 설치된 것을 씀, 다른 위치면 `CHROME_PATH`).
- 결과: `test-data/capture/latest/*.png`와 `결과.md`(찍은 목록·실패·콘솔 오류). git에 올라가지 않습니다.
- 찍는 화면: 학년부장(대시보드·나이스 자료 관리·학급 목록·1반 명렬표·커트라인·계정·상담 창·매트릭스·입시 분석), 담임(대시보드·명렬표), 진로부장(대시보드·학급 둘러보기).
- 담임·진로부장 계정은 사본에서 학년부장 권한으로 임시 비밀번호를 정해 로그인합니다.
- 새 화면을 만들면 `capture.js`의 시나리오에 한 줄씩 더합니다.
