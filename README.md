# 꼬미입시

울산 관내 중학교 3학년 고입 진학지도를 돕는 **Windows용 오프라인 프로그램**입니다. 나이스(NEIS) 엑셀 자료를 학교 PC 안에서만 처리하고, 고교별 산출식·지난 합격선·실제 지원 결과로 담임·진로 선생님의 1:1 상담을 돕습니다.

> 이 저장소는 **배포 전용**입니다. 프로그램 파일은 오른쪽 [Releases](../../releases)에서 받습니다.

## 받기와 설치

| 순서 | 할 일 |
|---|---|
| 1 | [최신 릴리즈](../../releases/latest)에서 `kkomi-ipsi_v<버전>.zip`(권장)을 받습니다 |
| 2 | **새 폴더**를 만들어 압축을 풀면 `꼬미입시.exe`가 나옵니다 |
| 3 | 실행하면 같은 폴더에 `data` 폴더가 생기고, 학교 자료는 모두 여기에 암호화되어 저장됩니다 |

### 처음 실행할 때 경고가 나오면

| 경고 | 누를 것 |
|---|---|
| Windows "PC 보호" 파란 창 | **[추가 정보]** → **[실행]** |
| 안랩 V3 "파일을 분석한다"는 알림 | **[허용]** 또는 검사가 끝날 때까지 기다림 |

코드 서명 인증서가 없는 프로그램이라 Windows가 만든 사람을 몰라서 나오는 경고입니다. V3 알림은 V3가 처음 보는 파일을 스스로 검사하는 기능입니다. 꼬미입시가 무엇을 보내는 것이 아닙니다.

### 받은 파일 확인하기 (지문값)

릴리즈마다 있는 `SHA256SUMS.txt`의 값과 아래 명령으로 나온 값이 같으면, 받은 파일이 바뀌지 않은 것입니다.

```powershell
Get-FileHash .\꼬미입시.exe -Algorithm SHA256
```

## 업데이트

v1.7.0 이후 버전은 프로그램을 켤 때 새 버전을 알려 줍니다. **[지금 업데이트]**를 누르면 다음 순서로 진행됩니다.

1. 새 버전을 받아 지문값을 확인합니다.
2. 자료를 `업데이트전_백업` 폴더에 복사합니다.
3. 프로그램을 다시 켭니다.

## 역할

| 역할 | 할 수 있는 일 |
|---|---|
| 학년부장 | 학교 설정, 나이스 자료 올리기, 계정·공용 데이터 암호 관리, 커트라인·판정 기준, 담임 배포자료 만들기·취합, 원서 결과, 원서대장·지원현황, 관내 공유 |
| 담임 | 우리 반 명렬표·1:1 상담, 원서 입력, 상담 일지, 취합자료 내보내기 |
| 진로부장 | 전교 학생·현황 조회(읽기 전용) |

자세한 사용법은 프로그램 왼쪽 메뉴의 **[사용 설명서]**에 있습니다.

## 개인정보 원칙

- 학생 이름·성적·상담·지원·합격 기록은 **학교 PC 안에만** 저장하고 밖으로 보내지 않습니다.
- 학교 자료와 선생님끼리 주고받는 파일은 학교가 정한 **공용 데이터 암호(AES-256-GCM)**로 잠깁니다.
- 인터넷은 업데이트 확인과, 선생님이 직접 누르는 **[💬 의견]** 보내기·답장 확인에만 씁니다. 의견에 학생 이름 등 개인정보가 들어 있으면 보내지 않습니다.
- 모든 산출·판정은 상담 참고 자료입니다. 원서 접수 전에는 그해 고교 공식 요강·산출표와 표본 학생으로 꼭 대조해 주세요.
